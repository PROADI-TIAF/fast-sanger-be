Rename .ab1 files

These files do not follow Sample_Guide[_Guide2...]_ABE|CBE_F|R.ab1. Fill in the fields and the files will be renamed when you continue in the terminal. Fields were pre-filled where the old name allowed a guess; check them. The ↓ button copies a value to every row below.

Current fileIncludeSampleGuide(s), comma-separatedEditorReadNew name
After saving, go back to the terminal and type y to rename the files and continue (or n to abort).
Uncheck Include for files that should be left untouched and skipped in this run.
Sample and guide names: letters, digits and hyphens only (no underscores). A sample analysed with several guides lists all of them, e.g. sg1, sg2.
Every rename is logged in rename_log.tsv so it can be undone.
