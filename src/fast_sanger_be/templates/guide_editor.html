Guide sequences

Enter each guide (protospacer, 5'→3', without the PAM). Names must match the guide names used in the .ab1 file names. You can paste two columns (name, sequence) straight from Excel.

#Guide nameSequence (5'→3')Length
After saving, go back to the terminal and type y to continue (or n to abort).
The file is saved as next to your .ab1 files, in this format:
>Guide-name on one line and its sequence on the next.
Names may contain letters, digits and hyphens (no underscores). Sequences: A, C, G, T only, 15–30 nt.
